# 사선 멀티 마스크

## 2차 수정 — 비교 영상 사용자 승인 (2026-11-22)

사용자가 원본과 다르다고 지적한 뒤 원본의 0–10초 작품 영역을 재검토했다. 아래의 최초 구현 설명 중 '인접 컷 최대 3장', '현재 컷 한 장으로 마무리'는 잘못 해석한 설계이며 2차 수정에서 폐기했다.

- 첫 컷: 같은 전체 사진의 세로 4개 영역이 중앙 블록으로 순차 등장한 뒤 하나씩 전체 높이로 확장한다. 원본 숫자·로고는 복사하지 않는다.
- 이후 컷: 모든 사선의 꼭짓점은 화면 왼쪽 아래 `(0,H)`에 고정된다. 새 컷은 위쪽 왼편에서 회전하는 마스크로 등장한다.
- 지난 컷은 아래에 쐐기 모양으로 누적한다. 새 컷 진입과 컷 진행에 따라 조각이 점차 얇아지며, 미래 컷을 미리 표시하지 않는다.
- 시간만으로 현재/이전 컷 상태를 재구성하여 앞뒤 탐색이 동일하다. 기존 컷별 사진·음성 시간 매핑·엔딩 호출은 유지한다.
- 원본 작품은 편집기 안의 가로 16:9다. 비교 영상은 원본 작품 영역 `(0,152,720,405)`을 잘라 같은 16:9의 수정본과 나란히 배치했다. 오른쪽은 기존 카페 샘플 사진이며 원본 소재를 앱 스타일에 넣지 않았다.
- 비교 범위는 0–9.8초의 4분할 도입과 누적 마스크다. 뒤쪽의 별도 패널/일반 영상 구간까지 복제했다고 주장하지 않는다. 원본 동영상의 피사체 움직임·음악·숫자 텍스트는 재현 대상이 아니다.
- 비교 생성: `tests/diagonal-fan-comparison.mjs`. 로컬 출력 `D:/AutoReelsLocal/StyleLab/diagonal-fan-v2/original-vs-revised.mp4`.
- 검증: 고정 꼭짓점/현재·이전 사진만 표시/4분할 도입·순차 확장/빈 사진·단일 사진/짧은 컷/되감기/엔딩/모바일·PC 선택 테스트. 최초 검사에서 수정 대상 외 전체 렌더 1,071개 디자인·5,355 프레임 오류 0 확인.
- 사용자가 비교 영상을 확인한 뒤 “좋아 반영해”로 운영 반영을 승인했다. 최신 main의 다른 스타일 정리 변경은 보존하고, 아래 검증 후 해당 수정본을 배포한다. 실제 배포 상태는 커밋의 Vercel 상태와 운영 브라우저 검사로 확인한다.

## 구현 경계

다음은 최초 배포본의 기록이며 위 2차 수정으로 대체할 예정이다.
- 카탈로그 ID `ref_e1e3436cf7c98bff`, 이름 **사선 멀티 마스크**, 기존 분류 **브이로그**.
- 전용 선언형 레이아웃 `diagonal-fan`; 기존 `diagonal` 한 사진 사선 띠와 구분.
- 직전 컷을 바탕으로 유지하고 인접 컷 사진 최대 3장을 다각형 마스크로 순차 확장. 마지막에는 현재 컷 사진만 전체 화면에 남는다.
- 컷별 `scenePlan.photoIdx` 우선, 사진이 적으면 기존 배치에 맞게 재사용. 끝 컷 이후 인덱스는 마지막 컷으로 제한해 처음 사진으로 돌아가지 않는다.
- 전환 길이는 컷 길이의 최대 62%로 제한. 시간값만으로 렌더링해 순서대로 재생하거나 뒤로 탐색해도 같은 결과다.
- 음성→가상 시간 변환, 컷 수, 대본, 기존 명함 엔딩 경로는 변경하지 않음. 고객이 지정한 이미지·영상 원본과 기존 오디오를 사용하고 새 AI 영상 생성은 하지 않음.
- 자막은 아래 안전 영역 위에 놓고 얇은 사선 경계만 표현한다. 글자 테두리 없음.
- 곡선·임의 도형 추적·3D 종이 접기·영상 속 피사체 움직임 복제는 지원 범위가 아니다.

## 분석기 연결
`lib/reference-style.cjs`에 허용값을 추가하고 서버 시각 분석 안내에 범위를 명시했다. 편집기 화면 녹화라도 미리보기에서 지원 가능한 사선 분할이 명확하면 UI를 제외한 스타일로 분석할 수 있다. 그 밖의 미지원 효과는 계속 보류한다.
기존 영상의 정규 URL 해시를 ID로 사용하므로 같은 링크 재요청 시 이미 등록된 스타일로 확인할 수 있다. 원래 실패 작업 기록은 삭제하지 않는다.

## 검증
`node tests/diagonal-fan-browser.mjs`: 서로 다른 4색으로 이전 컷+3개 레이어 검증, 빈 틈 없음, 컷별 사진 변경, 짧은 컷, 되감기, 빈 사진/단일 사진, 엔딩, 가변 음성 컷 매핑, 모바일/PC 선택.
`STYLE_PREVIEW_DIR`를 지정하면 기존 카페 샘플 사진으로 12초 미리보기와 장면 연락판을 만든다. 실제 고객 데이터나 유료 생성 API를 사용하지 않는다.
추가 검사: `node tests/reference-styles.cjs`, `node tests/production-safety.cjs`, `node tests/smoke-render.mjs`.

전체 기존 회귀 검사에는 이미 알려진 음성 최소 길이 정책 충돌(`narration-continuity`, 8초 대 2.93875초), TTS 버전 기대값 충돌(`export-safety`, 11 대 13), 숨긴 옛 스타일도 목록에 있어야 한다는 테스트(`reference-styles-browser`)가 있다. 이번 작업에서 기존 음성 정책이나 숨김 결정을 임의로 뒤집지 않는다. 새 레이아웃 자체 검사와 전체 검사 상태를 구분해 보고한다.
