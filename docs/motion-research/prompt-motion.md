# Prompt Motion 참고 적용 (2026-11-17)

참고: https://prompt-motion.com/ 및 https://prompt-motion.com/twoclipping-221cab

창작자의 프롬프트·코드·브랜드 시퀀스를 복제하지 않고, 마스크 등장과 시간 기반 모션이라는 일반 연출을 기존 Canvas 엔진에 직접 구현했다.

- 타이포 분류: 마스크 리빌(ty_mask), 워드 포커스(ty_focus), 스프링 스택(ty_spring).
- 기존 키네틱 포스터·시네마 키네틱에도 공통 마스크 자막을 적용했다.
- 전체 사진 위 3줄 한글 자막, 편집기의 위치·색·폰트·숨김 설정 유지.
- 등장 시간은 컷 길이의 28% 이내. 뒤쪽은 읽을 수 있게 유지한다.
- 워드 포커스 밑줄은 시각적 읽기 리듬이며 음성 단어 타임스탬프를 의미하지 않는다.
- Canvas 렌더링만 사용한다. 모델/API 호출, 새 생성 비용, 음성 길이 변경 없음.
- 한 번에 한 프레임을 시간으로 계산해 역방향 탐색과 내보내기에서도 동일하게 그린다.
