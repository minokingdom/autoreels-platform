# 포토 디스크와 네 컷 인화기

| 테마 | 원본 관찰과 스튜디오 적용 |
| --- | --- |
| 감성 · 포토 디스크 | [vinyl spinning](https://www.capcut.com/template-detail/vinyl-spinning/7378053320306330901). 28.3초 세로 영상. 바깥쪽 종이 사진은 고정되어 있고, 가운데 원형으로 자른 사진만 회전한다. 엔딩에서 전체가 어두워진다. 기존 ‘오후의 레코드’의 재킷과 검은 LP 구성을 사용하지 않는다. |
| 브이로그 · 네 컷 인화기 | [PHOTOBOOTH](https://www.capcut.com/template-detail/PHOTOBOOTH/7656434270189227271). 6.13초 세로 영상. 금속 슬롯에서 2×2 인화지가 아래로 밀려 나오며 아랫줄이 먼저 보인다. 슬롯은 고정된다. 1~3컷은 같은 묶음의 사진을 반복하고, 5컷 이상이면 네 컷씩 새 인화지를 인쇄한다. |

원본 장면 시트와 편집 결과를 로컬 수집 폴더 `20261128-vinyl-booth`에 보관한다. 처음과 끝의 문구는 컷 대본에서 바꾼다. 릴스의 재생 시간과 컷별 음성 길이는 기존 편집기 타임라인을 따른다. 회전은 영상 진행률로, 인화지 이동은 해당 네 컷 묶음의 진행률로 계산해 되감기에서도 같은 프레임을 얻는다.
