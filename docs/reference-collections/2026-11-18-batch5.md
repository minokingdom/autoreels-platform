# 스타일 수집 5차 — 핀터레스트

사용자가 로그인한 Ego 브라우저에서 실제 핀과 재생 미디어를 확인했다. 영상 3개는 로컬 rea-video로 분해하고 VIDEO.md, 타임라인, 스토리보드, 총 32개 감지 구간 연락판을 검토한 뒤 apply-review를 반영했다. RUN 포스터 1개는 정적 이미지로 검토했으며 움직임을 관측한 것처럼 기록하지 않는다. 영상의 자동 3D/AI 추정은 레이어 합성 화면과 일치하지 않아 시각 근거를 기록했다. 오디오의 출처는 미확인이다.

4개 추가: 고급/모노 타이포 포토 레일, 타이포/애로우 타이포 보드, 스포츠/리핏 포토 포스터, 감성/페이퍼 브러시 프레임. 참조 스타일 누적 17개. 신규 분류 추가 0개, 유료 분석·생성 API 호출 0회. 등록 시점부터 168시간 신규 탭에도 보이며 이후 기존 분류에 남는다.

운영 1920×910 화면에서 추천 영역이 카테고리 행을 12px로 압축해 클릭을 가리는 현상을 발견했다. 패널 전체 스크롤과 자식 영역 축소 방지로 해결하며 1920/1280/390 폭에서 실제 신규 탭·스타일 클릭을 검증한다. 서비스 화면에 출처 UI는 추가하지 않는다.

## 독립 에이전트 비교 검증

사용자 요청으로 별도 검증 에이전트가 원본 프레임·포스터·완성 미리보기·코드를 확인했다. 여러 줄 자막의 하단 넘침, 긴 문장 생략, 포토 레일 제목/본문 겹침 3건을 발견했다. 원문과 수동 줄바꿈을 보존하는 폭·높이 맞춤 함수와 제목 영역 제한으로 수정했다.

독립 재검증: 4스타일×7자막=28케이스, 현재 컷/scenePlan 반전 사진 16케이스 통과. 1920×910·1280×900·390×844에서 신규 탭·스타일 선택·자동 닫힘·재열기·닫기 통과. 판정은 수정 후 공개 가능이다. 매우 긴/무공백 문장은 글자가 작아지는 가독성 한계가 남는다. 별도 사람이 검수하거나 음성을 직접 청취한 것은 아니다.
