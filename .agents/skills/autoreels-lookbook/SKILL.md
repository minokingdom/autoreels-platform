# 오토릴스 룩북

[승인된 룩북 시안](assets/lookbook-reference.jpg)을 먼저 본다. 이 예시는 청바지와 면바지를 두 코디씩 비교한다. 다른 주제에서는 전달할 이야기에 맞춰 장수와 구성을 달리한다.

## 장을 넘기는 이유

- 표지에서 짧은 질문을 던지고, 비교할 인물이 같은 프레임에 들어 있는 단체 착용컷 한 장을 쓴다. 예시의 네 사람은 한 화면에 함께 서 있다. 각 인물의 사진을 격자로 나누는 구성은 상세 카드에서만 검토한다.
- 상세는 한 장에 한 코디를 담는다. 오른쪽에 전신 착용컷, 왼쪽에 그 코디에 쓰인 상의·하의·신발 등의 개별 상품컷을 놓는다. 상품 사진이 없는 컷은 착용컷을 중심에 둔다.
- 제품 이름만 반복하지 말고 사진의 차이를 읽어주는 한 줄을 붙인다. 예를 들어 진청은 “진청으로 단정하게”, 연청은 “연청으로 가볍게”처럼 옷감과 인상이 연결되게 쓴다.
- 마지막 장에는 앞에 본 선택지를 짧게 다시 보여주고, 댓글로 고를 수 있게 한 가지 행동을 제안한다. 투표가 어울리지 않는 주제에는 실제 다음 행동을 쓴다.

## 사진과 글자

차분한 종이색, 정렬이 맞는 여백, 실제 글꼴로 조판한 한글 명조 제목과 작은 산세리프 보조 글자를 사용한다. 타이포와 사진은 한 장의 여백과 정렬선을 공유한다. 표지와 착용컷은 원본 비율에 맞춰 인물의 얼굴부터 신발까지 화면에 둔다. 인물과 상품의 디테일이 글자에 가리지 않도록 여백을 본 뒤 줄바꿈과 글자 크기를 정한다. 비교군의 색은 작은 구분선과 제목에 절제해서 사용한다. 실제 상품과 시연용 이미지·코디를 구분한다.

## 형식

- 카드뉴스는 각 장을 4:5 이미지로 완성한다. 승인된 카드뉴스를 릴스로 바꿀 때는 완성된 4:5 이미지 자체를 사용한다. **사진 → 룩북 사진 → 완성 카드 그대로**를 켠 뒤 각 장을 순서대로 올린다. 9:16에 필요한 위아래 여백을 두고 카드 안의 사진, 글꼴, 배치, 여백을 유지한다.
- 릴스 스타일은 **디자인 → 카드뉴스 → 룩북 · 고정 카드**다. 직접 구성할 때는 기본 사진 칸에 단체 표지와 착용컷을 넣고, **사진 → 룩북 사진**에서 상세 컷마다 상품 사진을 최대 네 장 지정한다. 한 컷의 사진·자막·장식을 정지 상태로 렌더링하고 컷 경계에서 바로 다음 장으로 바꾼다. 영상 클립은 정지 프레임으로 쓴다. 성우·음악·컷 길이는 기존 제작 흐름을 사용하고, 설정된 명함은 고정 엔딩으로 표시한다.
- 스타일을 수정할 때는 docs/design-system.md를 읽고, 두 시각의 같은 컷이 같고 경계를 넘긴 다음 컷이 달라지는지 스튜디오에서 확인한다.
