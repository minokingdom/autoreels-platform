유료 분석 API 호출 0회. rea-video 로컬 분석과 Codex의 스토리보드·모든 구간 연락판 검토를 이용했다. 새 후보 5개 중 4개를 다운로드했으며 1개는 HTTP 403으로 제외했다. 다운로드된 1개는 전체 시각 검토가 끝나지 않아 보류했다. 지난 배치에서 엔진 미지원으로 보류한 2개는 이번에 사선 마스크와 글자 속 사진 효과를 구현하여 다시 검토했다.

5개 참조의 감지 구간 총 35개를 직접 확인하고 apply-review를 실행했다. 긴 구간에 여러 실제 사진/자막 교체가 들어 있어 감지 구간 수를 실제 편집 컷 수로 단정하지 않는다. 자동 통계의 live action/AI/3D 분류와 시각 검토가 상충하는 경우가 있었으며, 사진의 생성 출처와 오디오 출처는 미확정이다.

원본 사진·로고·문구·음악은 배포하지 않는다. 오토릴스의 사진과 대본에 구도 및 등장 효과만 적용한다. 사선 및 폴라로이드 효과는 현재 컷 사진 한 장만 사용한다. 모노 에코와 딥그린 플로는 사진을 쓰지 않는 타이포 전용 구성이다. 원본에서 채택한 부분과 재현하지 않은 효과는 JSON의 adaptationLimits에 남겼다. source-in 글자 마스크 캔버스를 재사용하고 기존 음성 기준 타임라인·엔딩 동작을 사용한다.

고정 구도 5개는 기존 일반 레이아웃의 위치/등장/전환 선택을 따로 적용하지 않는다. 생성 분석 프롬프트에도 제한을 명시했다. 카카오 수신 메시지나 자동 분석 이력을 가짜로 만들지 않았다. 이번 작업은 수동 수집 배치이며 정기 실행을 새로 등록하지 않았다.
