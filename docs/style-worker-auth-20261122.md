# 카카오 영상 분석 인증 분리

## 원인
작업 3979376229464332289는 영상 다운로드와 12개 프레임 추출에 성공했지만, 회원용 `reference-style` API에 로그인 없이 요청하여 401로 중단됐다. 카카오·Facebook 로그인 문제가 아니다. 스타일 등록과 배포는 실행되지 않았다.

## 연결 방식
- 기존 회원용 생성 API의 로그인 보호는 유지한다.
- 봇은 `POST /api/generate-script`, `mode: reference-style-worker`만 사용하는 별도 인증 경로로 연결한다.
- Vercel Production의 `REFERENCE_STYLE_WORKER_TOKEN`과 실행 PC의 `style-worker-credential.xml`에 같은 32바이트 임의 키를 설정한다. PC 파일은 Windows DPAPI로 암호화하며 현재 실행 사용자만 복호화한다. 비밀값은 저장소·로그·카톡에 넣지 않는다.
- 키는 다른 생성 모드나 계정 API에 사용할 수 없다. API 리다이렉트에는 키를 전달하지 않는다.
- 한국 시간 일일 40회 서비스 한도 및 전체 AI 예산을 DB 트랜잭션으로 예약한다. DB 확인 실패 시 공급자를 호출하지 않는다.
- 요청 번호를 DB에 기록하고 같은 번호의 동시/반복 요청을 거절한다. 실패 영수증도 유지하고 자동 재시도하지 않는다.
- 인증 오류는 사용자에게 로그인을 요구하지 않고 분석기 인증 연결 문제로 안내한다.

## 검증 및 전환
`node tests/production-safety.cjs`, `python tests/style-worker-auth.py`, 문법 검사와 기존 화면 스모크 검사를 통과한 뒤 서버를 배포한다. 운영 API에서 무인증 거절과 인증 경로를 확인하고 PC 작업기 파일을 백업·교체한다. 원래 실패 기록은 보존하며, 사용자 요청에 따른 재검증은 새 요청 번호로 한 번만 실행한다. 실제 분석 결과 검증과 배포 성공을 확인하기 전 스타일 추가 완료라고 알리지 않는다.

## 복구
기존 작업기를 종료하고 백업한 파일로 복구할 수 있다. 전용 키를 제거하면 봇 분석은 차단되며 회원 로그인이나 결제에는 영향을 주지 않는다. 원래 원인은 구버전 무인증 요청이므로 파일 복원만으로 분석이 복구되지는 않는다.

## 별도 발견 사항
`tests/export-safety.mjs:107`은 기존 성우 API 버전을 11로 기대하지만 최신 클라이언트는 13을 사용하여 실패한다. 이번 수정은 성우 코드·화면·해당 테스트를 변경하지 않는다. 운영 안전 테스트와 화면 스모크는 통과했으며, 이 별도 테스트의 버전 불일치는 기존 담당 작업에서 확인해야 한다.
